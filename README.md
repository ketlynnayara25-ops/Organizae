## 📌 Sobre o projeto

O **Organizae** é uma proposta de plataforma digital, disponível em site e aplicativo, que tem como objetivo ajudar estudantes a organizar suas atividades acadêmicas, acompanhar prazos e receber lembretes sobre datas importantes.

A plataforma busca tornar a rotina acadêmica mais prática, produtiva e organizada.

## ❗ Problema identificado

Na rotina acadêmica, muitos estudantes enfrentam dificuldades como:

- Esquecimento de datas de entrega;
- Acúmulo de atividades;
- Falta de organização;
- Dificuldade para acompanhar várias matérias;
- Perda de prazos importantes.

## 💡 Nossa solução

O Organizae propõe centralizar a organização acadêmica em uma única plataforma, permitindo:

- Organização de atividades por matéria;
- Calendário acadêmico;
- Acompanhamento de entregas;
- Visualização dos prazos;
- Notificações e lembretes;
- Sincronização entre site e aplicativo.

## 👨‍🎓 Área do aluno

- Tela inicial;
- Resumo das atividades;
- Matérias cadastradas;
- Próximas entregas;
- Atividades urgentes;
- Calendário acadêmico;
- Modo Foco.

## 👩‍🏫 Área do professor

- Gerenciamento de turmas;
- Cadastro de matérias;
- Criação de atividades;
- Definição de datas de entrega;
- Acompanhamento das entregas;
- Organização das atividades dos alunos;
- Visualização de relatórios.

## 🎨 Sistema de cores

| Cor | Situação |
|---|---|
| 🟢 Verde | Atividade entregue |
| 🟡 Amarelo | Atividade pendente |
| 🟠 Laranja | Prazo próximo |
| 🔴 Vermelho | Atividade atrasada |

## 🔔 Notificações e lembretes

- Lembretes por e-mail;
- Notificações pop-up;
- Aviso antecipado de 5 dias antes da entrega;
- Alertas de atividades próximas do vencimento.

## ⚙️ Funcionalidades adicionais

- 💬 Chat para consultas e dúvidas;
- 🎙️ Comandos de voz;
- 📚 Organização por matérias;
- 💻 Acesso por computador e celular;
- 🎯 Modo Foco;
- 🖥️ Interface intuitiva.

## 🚀 Benefícios esperados

**Para os alunos:**
- Mais organização;
- Menos esquecimentos;
- Melhor gerenciamento do tempo;
- Maior controle das entregas.

**Para os professores:**
- Facilidade para cadastrar atividades;
- Melhor acompanhamento das turmas;
- Visualização das entregas;
- Comunicação mais organizada.
